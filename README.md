# OmaGAWD

Winamp-inspired music player for Omarchy. **Jellyfin + local files.**

![OmaGAWD](preview.png)

```sh
./scripts/install.sh
```

Open the llama icon. Choose music from the source menu. **Manage sources…** adds or removes local sources without deleting files.

| Shortcut | Action |
|---|---|
| P / L | Playlist / library |
| ⌘F | Search |
| Tab | Switch lists |
| Arrows / Space | Browse / select |
| Return / double-click | Play |
| Option-click / Option-Return | Add to queue |
| Delete | Remove from queue |
| Option+↑/↓ | Reorder |
| Escape | Hide |
