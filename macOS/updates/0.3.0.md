# OmaGAWD for macOS 0.3.0

- Browse All artists... / All albums... without losing search, and play or append the matching group. Shuffle/repeat now have native icons, accent-colored active indicators and clear current-mode descriptions.
- Save, preview, rename and load named playlists on this Mac. Return to recently played albums and radio stations from Playlist → Recent.
- Browse Jellyfin playlists, create a private playlist from a Jellyfin queue on supported servers, and delete a playlist after confirmation and a fresh permission check. Songs and the current queue are kept.
- Use the in-app Settings page for playback options, sources, updates and shortcuts. Add files/folders with the native picker or drop music onto the player.
- Enable gapless preloading and optional native live volume normalization. Control recent history and llama motion.
- Enjoy the smoother head-bang shoulder and slightly larger monochrome menu bar llama.
- Session saving now coalesces rapid edits, enforces 100,000-track / 64 MiB limits, writes private atomic files, preserves the previous save on failure, and flushes the latest queue at shutdown.
- Tighten saved remote-account checks and music-input limits, and keep source imports/removals from interrupting the queue.

Playback restores paused. Network conditions and native format support can still affect transitions. Live-radio normalization requires macOS 27 or later. This native live loudness control uses sample-peak protection; it differs from Omarchy's integrated R128/true-peak filter.
