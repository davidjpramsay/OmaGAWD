# OmaGAWD 0.2.1 beta

- Check for Updates is available from the player's gear menu and the OmaGAWD application menu.
- Download, verify, install and restart the app without replacing it manually.
- Update checks are manual by default. Background checks, unattended installation and system profiling are disabled.
- Updates and the macOS release feed are signed; the app and installer are Apple notarized.

Your queue and playback position are kept when the app restarts. Playback starts paused.
